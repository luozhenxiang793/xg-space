方向一：红军路径规划（T1-T10）

T1

红军侦察兵在n×m的网格地图上执行侦察任务，从左上角出发，每次只能向上下左右移动一步。要遍历所有可达格子且不重复访问，最适合使用的搜索策略是：

A. 广度优先搜索（BFS）
B. 深度优先搜索（DFS）
C. Dijkstra算法
D. 二分查找
答案：B

题目要求"遍历所有可达格子且不重复访问"，这是典型的图遍历问题。DFS沿着一条路走到底再回溯，适合遍历所有节点。BFS按层扩展，虽然也能遍历所有节点，但需要更多内存（队列中同时存储更多节点）。Dijkstra用于求最短路径，二分查找用于有序数组，都不适用。

知识点：DFS vs BFS的选择——遍历所有路径/节点用DFS，求最短路径用BFS。

T2

在BFS求最短路径的算法中，使用队列（queue）的核心原因是：

A. 队列可以自动排序
B. 队列保证先访问的节点先被扩展（先进先出）
C. 队列可以存储所有节点的最短距离
D. 队列比数组更快
答案：B

BFS的核心是"按层扩展"——先扩展距离起点近的节点，再扩展距离远的节点。队列的"先进先出"（FIFO）特性正好保证了这一点：先入队的节点（距离近）先出队被扩展。这样第一次到达某节点时一定经过最少的步数。

知识点：BFS用队列（FIFO），DFS用栈（LIFO）或递归调用栈。

T3

在n×m的网格中进行BFS，方向数组的写法如下：

int dx[] = {-1, 1, 0, 0};
int dy[] = {0, 0, -1, 1};

这四个方向分别表示：

A. 左、右、上、下
B. 上、下、左、右
C. 上、下、右、左
D. 北、南、西、东
答案：B

dx[0]=-1, dy[0]=0：行减1，即向上（北）

dx[1]=1, dy[1]=0：行加1，即向下（南）

dx[2]=0, dy[2]=-1：列减1，即向左（西）

dx[3]=0, dy[3]=1：列加1，即向右（东）

所以顺序是：上、下、左、右。

知识点：方向数组的含义取决于坐标系定义。行号增大=向下，列号增大=向右。

T4

某次BFS中，起点到某点的最短距离为5。如果图中所有边的权重都改为2，那么BFS求出的最短距离变为：

A. 5
B. 10
C. 不确定
D. BFS无法求解
答案：D

BFS只能处理无权图（所有边权重相同且为1）。当边权变为2时，虽然仍然是"等权图"，但BFS记录的"步数"需要乘以2才是实际距离。更重要的是，如果边权不相等（有的边权重1，有的权重2），BFS就无法保证找到的是最短路径。此时应该使用Dijkstra算法。

知识点：BFS处理无权图最短路，Dijkstra处理非负权图最短路。

T5

以下关于Dijkstra算法的说法，错误的是：

A. 每次选择距离起点最近的未确定节点
B. 可以处理含有负权边的图
C. 时间复杂度为O(n²)（朴素实现）
D. 使用贪心策略
答案：B

Dijkstra算法不能处理负权边！因为Dijkstra基于贪心思想——一旦确定某节点的最短距离就不再更新。如果存在负权边，已确定的距离可能通过负权边变得更短，导致算法出错。负权图需要使用Bellman-Ford或SPFA算法。

知识点：Dijkstra的限制——不能有负权边；适用条件——所有边权≥0。

T6

在BFS中，visited数组的作用是：

A. 记录每个节点到起点的最短距离
B. 防止同一个节点被重复访问，避免死循环
C. 存储图的邻接矩阵
D. 记录每个节点的前驱节点
答案：B

在图的搜索中，如果不标记已访问的节点，可能会出现：A→B→A→B→...的死循环。visited数组标记哪些节点已经访问过，遇到已访问节点直接跳过。记录最短距离用dist数组，记录前驱用pre数组，存储图用邻接矩阵或邻接表。

知识点：visited数组是BFS/DFS的标准配置，防止重复访问和死循环。

T7

以下哪种情况适合用DFS而不是BFS？

A. 求迷宫中从起点到终点的最短路径
B. 枚举从起点到终点的所有可行路径
C. 求无权图中两点间的最少步数
D. 按层遍历二叉树
答案：B

A、C都是求最短路径，适合BFS

B是枚举所有路径，DFS沿着一条路走到底再回溯，天然适合穷举

D是按层遍历，BFS的典型应用

DFS的递归+回溯结构非常适合"枚举所有可能性"的问题。

知识点：BFS→最短路径/按层遍历；DFS→枚举所有路径/回溯搜索。

T8

某网格地图为3×3，全部为可通行区域（0）。从(0,0)到(2,2)，只能向下或向右走，共有多少条不同路径？

A. 4
B. 6
C. 8
D. 12
答案：B

从(0,0)到(2,2)需要走4步：恰好2步向下 + 2步向右。问题等价于在4步中选择2步向下（其余自动向右），即组合数 C(4,2) = 4!/(2!×2!) = 6。

也可以手动枚举：

1. 下下右右 2. 下右下右 3. 下右右下 4. 右下下右 5. 右下右下 6. 右右下下

知识点：网格路径计数=组合数学。从(0,0)到(n-1,m-1)需要(n-1)步下+(m-1)步右，共C(n+m-2, n-1)条路径。

T9

BFS求最短路径时，如果需要输出具体的最短路径（而不只是距离），需要额外维护的数据结构是：

A. visited数组
B. 前驱数组（记录每个点是从哪个点扩展来的）
C. 邻接矩阵
D. 栈
答案：B

BFS默认只记录距离，不记录路径。要输出具体路径，需要在BFS过程中记录每个节点的"前驱"——即它是从哪个节点扩展来的。到达终点后，沿着前驱链从终点回溯到起点，再反转即可得到完整路径。

知识点：路径记录=BFS+前驱数组（pre_x, pre_y）+回溯输出。

T10

关于栈（stack）和队列（queue），以下说法正确的是：

A. 栈是先进先出（FIFO），队列是后进先出（LIFO）
B. 栈是后进先出（LIFO），队列是先进先出（FIFO）
C. 栈和队列都是先进先出
D. 栈和队列都是后进先出
答案：B

栈（Stack）：后进先出（LIFO），像叠盘子，最后放的最先拿走。DFS使用栈。

队列（Queue）：先进先出（FIFO），像排队，先来的先走。BFS使用队列。

知识点：栈→LIFO→DFS；队列→FIFO→BFS。这是最基础的数据结构概念。

方向二：革命物资分类（T11-T18）

T11

对数组 [5, 2, 8, 1, 9] 进行选择排序，第一轮结束后数组变为：

A. [1, 2, 8, 5, 9]
B. [2, 5, 8, 1, 9]
C. [1, 5, 8, 2, 9]
D. [5, 2, 1, 8, 9]
答案：A

选择排序第一轮：从整个数组中找到最小值1（下标3），与第一个元素5交换。

交换前：[5, 2, 8, 1, 9]

交换后：[1, 2, 8, 5, 9]

第一轮结束后，最小值1已经在正确位置。

知识点：选择排序每轮：找最小值→交换到当前位置。第i轮后前i+1个元素有序。

T12

对数组 [3, 1, 4, 1, 5] 进行冒泡排序，第一轮比较交换后数组变为：

A. [1, 3, 1, 4, 5]
B. [1, 1, 3, 4, 5]
C. [3, 1, 1, 4, 5]
D. [1, 3, 4, 1, 5]
答案：A

冒泡排序第一轮：相邻元素两两比较，把最大值"冒泡"到末尾。

比较3和1：3>1，交换 → [1, 3, 4, 1, 5]

比较3和4：3<4，不换 → [1, 3, 4, 1, 5]

比较4和1：4>1，交换 → [1, 3, 1, 4, 5]

比较4和5：4<5，不换 → [1, 3, 1, 4, 5]

第一轮结束后，最大值5已经在最后。

知识点：冒泡排序每轮：相邻比较+交换，最大值"冒泡"到末尾。

T13

以下排序算法中，时间复杂度为O(n log n)的是：

A. 选择排序
B. 冒泡排序
C. 归并排序
D. 以上都不是
答案：C

选择排序：O(n²) —— 双重循环

冒泡排序：O(n²) —— 双重循环

归并排序：O(n log n) —— 分治思想，每次折半

C++ STL的sort()函数内部使用了优化的排序算法（混合排序），平均时间复杂度为O(n log n)。

知识点：O(n²)排序：选择、冒泡、插入；O(n log n)排序：归并、快排、堆排序。

T14

使用C++ STL的sort函数对数组a（共n个元素）从小到大排序，正确的调用方式是：

A. sort(a, a+n);
B. sort(a, n);
C. sort(a[n]);
D. sort(&a, &a+n);
答案：A

sort()的参数是排序范围的起始地址和结束地址的下一个位置。

sort(a, a+n)：从a[0]到a[n-1]，共n个元素，正确

sort(a, n)：第二个参数应该是地址，不是数量

sort(a[n])：a[n]是越界元素，不是有效范围

sort(&a, &a+n)：&a是整个数组的地址，类型不匹配

知识点：sort(起始地址, 结束地址+1)，左闭右开区间 [begin, end)。

T15

以下关于贪心算法的描述，正确的是：

A. 贪心算法一定能得到全局最优解
B. 贪心算法每步选择当前最优解，不考虑未来
C. 贪心算法比动态规划更慢
D. 贪心算法只能用于排序问题
答案：B

A错误：贪心不一定得到全局最优，只有满足"贪心选择性质"和"最优子结构"时才行

B正确：贪心的核心就是"只看眼前，选当前最好的"

C错误：贪心通常比动态规划更快

D错误：贪心广泛用于调度、图论、背包等问题

知识点：贪心算法的适用条件——问题具有贪心选择性质和最优子结构。

T16

对n个物品按"价值/重量"比值从大到小排序，然后依次选取，直到总重量超过限制。这是哪种算法思想？

A. 动态规划
B. 贪心算法
C. 分治算法
D. 回溯算法
答案：B

按"性价比"（价值/重量）排序后依次选取，每次选"性价比最高"的物品，这是典型的贪心策略。这种思路用于"分数背包问题"（物品可以分割），可以得到最优解。但对于"0-1背包问题"（物品不可分割），贪心不一定最优，需要动态规划。

知识点：贪心在背包问题中的应用——分数背包用贪心，0-1背包用DP。

T17

比较两个分数 a/b 和 c/d 的大小（b,d ≠ 0），为避免浮点数精度问题，最佳做法是：

A. 直接计算 a/b 和 c/d，比较浮点结果
B. 比较 a*d 和 c*b 的大小（假设b,d同号）
C. 先通分再比较分子
D. 将分数转换为百分比
答案：B

A方法有浮点精度风险：0.1+0.2 ≠ 0.3

B方法是"交叉相乘"：a/b > c/d ⟺ a×d > c×b（当b,d>0时），全程整数运算，无精度损失

C方法正确但实现复杂

D方法不实用

知识点：比较分数大小用交叉相乘，避免浮点精度问题。这是编程竞赛中的常用技巧。

T18

以下代码实现的是哪种排序？

for (int i = 0; i < n - 1; i++)
    for (int j = 0; j < n - 1 - i; j++)
        if (a[j] > a[j+1])
            swap(a[j], a[j+1]);
A. 选择排序
B. 冒泡排序
C. 插入排序
D. 快速排序
答案：B

外层循环控制轮数

内层循环从头开始，相邻元素比较 a[j] > a[j+1]，如果逆序就交换

每轮结束后最大值"冒泡"到末尾，所以内层上界是 n-1-i（已排好的不再比较）

这是冒泡排序的标准写法。选择排序是"找最小值+交换"，插入排序是"找位置+插入"。

知识点：冒泡排序特征——相邻比较+交换；选择排序特征——找最小值+交换到前面。

T19

以下代码的功能是：

int sum = 0;
for (int i = 0; i < n; i++)
    sum += a[i];

A. 求数组的最大值
B. 求数组的平均值

D. 对数组排序

T20

以下代码找数组中的最大值，横线处应填什么？

int maxVal = a[0];
for (int i = 1; i < n; i++)
    if (________)
        maxVal = a[i];
A. a[i] > maxVal
B. a[i] < maxVal
C. a[i] == maxVal
D. a[i] != maxVal
答案：A

找最大值的逻辑：遍历数组，如果当前元素比已知最大值更大，就更新最大值。所以条件是a[i] > maxVal。

如果要找最小值，条件改为a[i] < minVal。

知识点：求最值——初始化为第一个元素，遍历比较更新。

T21

在有序数组中查找元素，二分查找的时间复杂度是：

A. O(1)
B. O(log n)
C. O(n)
D. O(n log n)
答案：B

二分查找每次将搜索范围缩小一半：

第1次：搜索范围n

第2次：搜索范围n/2

第3次：搜索范围n/4

...

第k次：搜索范围n/2^k

当n/2^k = 1时找到，k = log₂(n)，所以时间复杂度为O(log n)。

对于n=100000，二分查找最多只需约17次比较，而顺序查找最坏需要100000次。

知识点：二分查找O(log n)，顺序查找O(n)。有序数组用二分，效率提升巨大。

T22

二分查找的前提条件是：

A. 数组元素互不相同
B. 数组已经排好序
C. 数组元素都是正整数
D. 数组长度为偶数
答案：B

二分查找的核心是"中间元素与目标值比较，决定在左半还是右半查找"。这要求左半部分都比中间值小，右半部分都比中间值大——即数组必须有序。如果数组无序，二分查找可能遗漏目标值。

知识点：二分查找的必要条件——数组有序。无序数组需要先排序。

T23

以下代码的功能是统计数组中有多少个偶数，横线处应填什么？

int count = 0;
for (int i = 0; i < n; i++)
    if (________)
        count++;
A. a[i] % 2 == 0
B. a[i] / 2 == 0
C. a[i] % 2 == 1
D. a[i] * 2 == 0
答案：A

判断偶数的条件是"能被2整除"，即a[i] % 2 == 0（取模余数为0）。

a[i] / 2 == 0：当a[i]为0或1时成立，不是判断偶数

a[i] % 2 == 1：判断奇数

a[i] * 2 == 0：只有a[i]=0时成立

知识点：取模运算 % 是判断整除/奇偶的核心操作。

T24

以下代码对数组进行去重（假设数组已排序），输出不重复的元素。横线处应填什么？

cout << a[0];
for (int i = 1; i < n; i++)
    if (________)
        cout << " " << a[i];
A. a[i] != a[i-1]
B. a[i] != a[0]
C. a[i] > a[i-1]
D. A和C都对
答案：D

数组已排序时：

a[i] != a[i-1]：当前元素与前一个不同，说明不是重复值，输出

a[i] > a[i-1]：对于已排序数组（升序），不等价于"不重复"——如果数组有降序部分就不对

等等，对于升序排列的数组，a[i] != a[i-1]和a[i] > a[i-1]是等价的（因为升序时a[i] >= a[i-1]，不相等就一定大于）。

所以A和C都对，答案是D。

知识点：已排序数组去重——相邻比较即可。利用排序的有序性简化问题。

T25

以下代码使用lower_bound查找，假设数组a=[1,3,5,7,9]，lower_bound(a, a+5, 5)返回的是：

A. a[0]的地址（值为1）
B. a[2]的地址（值为5）
C. a[3]的地址（值为7）
D. a[5]的地址（越界）
答案：B

lower_bound(begin, end, value)返回第一个 ≥ value 的元素的位置。

数组：[1, 3, 5, 7, 9]

查找5：第一个≥5的元素是a[2]=5

返回a[2]的地址

相关函数对比：

lower_bound：第一个 ≥ value 的位置

upper_bound：第一个 > value 的位置

知识点：lower_bound和upper_bound是C++ STL的二分查找函数，要求数组有序。

T26

以下代码的输出是什么？

int a[] = {3, 1, 4, 1, 5, 9};
int n = 6;
int cnt = 0;
for (int i = 0; i < n; i++)
    if (a[i] > 3)
        cnt++;
cout << cnt;
A. 2
B. 3
C. 4
D. 5
答案：B

遍历数组，统计大于3的元素个数：

3 > 3? 否

1 > 3? 否

4 > 3? 是 → cnt=1

1 > 3? 否

5 > 3? 是 → cnt=2

9 > 3? 是 → cnt=3

输出3。

知识点：条件计数——遍历数组，满足条件时count++。

方向四：综合应用（T27-T34）

T27

阅读以下代码，当输入为 5 时，输出是什么？

int n;
cin >> n;
int sum = 0;

    sum += i;

A. 5
B. 10
C. 15
D. 120
答案：C

计算 1+2+3+4+5 = 15。这是求前n项自然数之和，也可以用公式 n*(n+1)/2 = 5*6/2 = 15。

T28

以下递归函数的功能是什么？

int f(int n) {
    if (n <= 1) return 1;
    return n * f(n - 1);
}
A. 求n的阶乘
B. 求斐波那契数列第n项
C. 求1到n的和
D. 求2的n次方
答案：A

基准情况：n≤1时返回1

递推关系：f(n) = n × f(n-1)

展开：f(5) = 5 × f(4) = 5 × 4 × f(3) = 5 × 4 × 3 × f(2) = 5 × 4 × 3 × 2 × f(1) = 5 × 4 × 3 × 2 × 1 = 120

这就是阶乘的定义：n! = n × (n-1)!

知识点：递归三要素——基准情况、递推关系、收敛（每次向基准靠近）。

T29

以下代码的功能是：

string s;
cin >> s;
int left = 0, right = s.length() - 1;
bool isPalin = true;
while (left < right) {
    if (s[left] != s[right]) {
        isPalin = false;
        break;
    }
    left++;
    right--;
}
cout << (isPalin ? "是回文" : "不是回文");
A. 反转字符串
B. 判断回文串
C. 统计字符个数
D. 查找字符
答案：B

双指针法判断回文：

left从左端开始，right从右端开始

比较s[left]和s[right]，如果不同则不是回文

相同时left++、right--，向中间靠拢

当left >= right时，所有对称位置都匹配，是回文

例如："abcba" → a==a ✓, b==b ✓, c（中间）→ 是回文

知识点：双指针法——从两端向中间收缩，是处理回文、两数之和等问题的常用技巧。

int a[] = {1, 2, 3, 4, 5};

D. 数组求和
答案：B
